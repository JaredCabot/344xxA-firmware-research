# Scope and redistribution notice

## Scope of this work
This project studies how the 3446xA firmware is built and how it works, for
documentation and interoperability. It explicitly does **not** attempt to defeat
or bypass instrument licensing, paid options, secure-code protection, or any
other protection mechanism. Where the firmware contains such mechanisms they are
noted by name only, without any procedure for enabling or bypassing them.

## Redistribution
The firmware package (`Agt3446XA_rev_A_03_03.upd`), the decompressed Windows CE
image, every binary extracted from it (Keysight `Torreys.*` and `Agilent.*`,
Microsoft Windows CE components, bundled fonts and JavaScript libraries), and the
Keysight PDF manual are copyrighted by their respective owners and are **not**
included in this repository. They are git-ignored. Only original analysis, notes,
and tools are committed here. Run the tools against your own copy of the firmware.
